# Grok の会話設定

Grok の chat を開くと、会話の上部に Model と Reasoning Effort が表示される。
会話を続けたまま切り替えられ、選択肢は起動中の Grok が返したものを使う。

- Model を替えて現在の effort が候補から外れた場合は、近い候補へ自動でそろえる。補正前後は select の隣に表示される。
- 応答生成中と設定切替中は select が無効になる。設定切替が終わってから次の操作を行う。
- 開き直した時や外から変更した時も、effort が候補外なら一度そろえる。そろえられない時は「候補外」と失敗理由を表示する。利用可能な effort を選んで再試行できる。
- 切替に失敗したら、表示された理由と現在値を確認する。model の変更だけ成功している場合もある。
- 「切替結果を確認できません」と出たら、現在値を確認して再試行する。

Grok が会話に設定を保存する。同じ会話を閉じて開き直す時は、その保存値を読み込む。
保存値の effort が候補外なら、開く時にそろえる。
設定面がまだ届いていない時は model の読み取り専用表示になる。Grok の chat を開いて接続完了を待つ。

実装と補正規則: [design 42 §7](../design/42-grok-acp-host.md#7-grok-の設定-panel)。
