# Editor で見た目を整える

Ctrl+Shift+E で Editor を開閉します。横並びの THEME → SIDEBAR → CHAT → COMPONENT タブで切り替え、初回は THEME が開きます。

- **THEME**: プリセットを選び、背景、Board の Markdown 本文、境界の動き、pane の名札の高さ、Lane の端末の文字（サイズ・行の高さ・文字の間隔）を調整します。端末の配色は別設定です。
- **SIDEBAR**: 選択せずに、左右の幅（左 peek の幅・右の幅）、左の文字、背景、選択行と状態ポイントを調整できます。「Lane＋メイン背景」は選択行とメインの両方に反映されます。「重ねる光」は hover や repo の地に重ねる薄い光の素で、Light Grid のまま地を明るくした時に暗くすると重ねが見えます。
  幅は境界を drag した時と同じ扱いで、テーマには入りません（テーマを切り替えても幅は変わらず、次回起動時も同じ幅で開きます）。
- **CHAT**: 返信、自分のメッセージ、ツール・思考、接続状態、ツール詳細の文字をまとめて調整します。すべての Chat に反映します。
- **COMPONENT**: 「画面から選ぶ」を押し、調整したい部品をクリックします。枠は選択位置を示します。変更は同じ種類の部品全体に反映されます。「一覧から探す」には現在画面にある部品の階層が出ます。

テーマごとの調整は自動保存されます。「カスタムテーマ名」を入力して「名前を付けて保存」すると、テーマ一覧から再利用できます。
保存済みのカスタムを編集したら「変更を保存」で確定できます。「保存した状態に戻す」で最後に保存した調整へ戻れます。
各項目の ↺ は、そのテーマの初期値に戻します。「調整値を書き出す」から JSON を取り出せます。

Esc は、選択操作の取り消し → 選択解除 → Editor を閉じる、の順で現在の状態に応じて働きます。

## 独立プレビュー

repo の lane ルートから:

```bash
cd crates/vp-app/webview
bun editor/preview.mjs 12889
```

[http://127.0.0.1:12889/](http://127.0.0.1:12889/) を開きます。
実際の Sidebar と Editor をサンプル状態で描画し、操作は daemon に送信しません。保存はこのプレビューの origin に閉じます。
ソース変更後はプレビューを起動し直し、ブラウザを再読込してください。既存プレビューとポートが重なる場合は引数で変更できます。

## 保存できない場合

保存先を利用できない旨が出たら、ページを閉じる前に「調整値を書き出す」の JSON をコピーしてください。
破損した保存データがあっても既定テーマで起動します。古い Editor の field 保存キーは移行後も残ります。

文字設定は適用先の名前で表示します。SIDEBAR の旧「本文」と、通常画面に適用先のない汎用 XS / S / M / XL・部品の間隔は操作欄から省きます。既存テーマの保存値と連携用 field は保持します。Board の文字設定は Markdown 表示向けで、埋め込んだ Web ページには適用されません。
