# Editor で見た目を整える

Ctrl+Shift+E で Editor を開閉します。上から THEME → SIDEBAR → COMPONENT の順に並び、初回は THEME が開きます。

- **THEME**: プリセットを選び、全体の文字や背景、Chat の文字、境界の動きを調整します。端末の配色は別設定です。
- **SIDEBAR**: 選択せずに、文字、背景、選択行と状態ポイントを調整できます。「Lane＋メイン背景」は選択行とメインの両方に反映されます。
- **COMPONENT**: 「画面から選ぶ」を押し、調整したい部品をクリックします。枠は選択位置を示します。変更は同じ種類の部品全体に反映されます。「一覧から探す」には現在画面にある部品の階層が出ます。

テーマごとの調整は自動保存されます。「カスタムテーマ名」を入力して「名前を付けて保存」すると、テーマ一覧から再利用できます。
保存済みのカスタムを編集したら「変更を保存」で確定できます。「保存した状態に戻す」で最後に保存した調整へ戻れます。
各項目の ↺ は、そのテーマの初期値に戻します。「調整値を書き出す」から JSON を取り出せます。

Esc は、選択操作の取り消し → 選択解除 → Editor を閉じる、の順で現在の状態に応じて働きます。

## 独立プレビュー

repo の lane ルートから:

```bash
cd crates/vp-app/webview
bun editor/preview.mjs 12889
```

[http://127.0.0.1:12889/](http://127.0.0.1:12889/) を開きます。
実際の Sidebar と Editor をサンプル状態で描画し、操作は daemon に送信しません。保存はこのプレビューの origin に閉じます。
ソース変更後はプレビューを起動し直し、ブラウザを再読込してください。既存プレビューとポートが重なる場合は引数で変更できます。

## 保存できない場合

保存先を利用できない旨が出たら、ページを閉じる前に「調整値を書き出す」の JSON をコピーしてください。
破損した保存データがあっても既定テーマで起動します。古い Editor の field 保存キーは移行後も残ります。
